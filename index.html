1. 画像と作品情報

アーティスト名とタイトルはハイフンでつないで背表紙に表示します。入力したタイトルとアーティスト名を文字で配置します。左側は−90度（下から上へ）、右側は＋90度（上から下へ）に回転し、左側と右側でY位置を反転し、参考画像のように配置します。背表紙のタイトルとカタログ番号は、それぞれ位置、文字サイズ、色、フォントを調整できます。

カタログ番号も左右の背表紙に同じ文字で配置し、左は−90度、右は＋90度に回転します。左右でY位置を反転し、参考画像のように配置します。

バックインレイ表の左右6mm部分に、文字の下地色を重ねます。

元画像の文字やデザインが左右端の6mm（背表紙部分）まである場合に使います。 チェックを入れると、バックインレイ表／裏のプレビュー（個別画像プレビュー）の両端に丸い点（ハンドル）が出ます。 片方の点を内側へドラッグすると、もう片方も同じ量だけ内側に動き、画像全体が左右対称に縮んで内側に収まります。両端の部分は、端の絵柄を引き伸ばしてつなぎます。

読み込んだフォントは、背表紙の文字に使用され、プレビューと書き出しにも反映されます。フォントファイル（TTF / OTF / WOFF / WOFF2）から読み込むこともでき、読み込んだフォントはプロジェクトファイルにも保存されます。

Windowsの標準フォントは C:\Windows\Fonts に入っています。ブラウザの仕様上、ファイル選択ダイアログの最初のフォルダーをサイト側から指定することはできません。下のボタンでパスをコピーして、ダイアログのアドレス欄（またはファイル名欄）に貼り付けると、そのフォルダーを開けます。

標準フォントを使用中です。

2. CD完成イメージ

3Dプレビューはドラッグで回転できます。PCではShift＋ドラッグまたは位置スライダー、タッチ端末ではタッチ操作で移動します。ケースの開閉、ディスクの着脱、60〜180%のズームも操作できます。

レイヤーでデザイン

画像レイヤーと文字レイヤーを追加できます。 各レイヤーはフロントジャケット、バックジャケット、バックインレイ表／裏、ディスクのいずれかに割り当てられます。 レイヤーごとに表示切替、重なり順、フォルダー分け、不透明度、ブレンドモード、指定色への変更を設定できます。色変更では画像の透明部分を保持します。 レイヤー設定と一覧は個別に折りたためます。 文字レイヤーは文字列、文字サイズ、文字色、フォントを個別に設定でき、フォントファイル（TTF / OTF / WOFF / WOFF2）も読み込めます。

変形

移動・変形モードはデフォルトでオフです。レイヤーを追加・選択しても自動ではオンになりません。 必要なときだけボタンでオンにすると、選択したレイヤーをプレビュー上をドラッグして移動でき、Shift＋ドラッグで拡大縮小できます。 拡大縮小スライダーはレイヤー全体に適用されます。

3. 画像アップロード・書き出し・ブックレット

名前で検索してプレビューしながらフォントを探せます。選んだフォントは背表紙や文字レイヤーに使えます。Google Fontsのフォントは選択時に読み込むためインターネット接続が必要です。端末のフォントは接続なしで使えます。

画像をアップロード

フロント・バックジャケットは2ページジャケット専用です。

ジュエルケースのディスクトレイが透明ではない場合、バックインレイ裏はトレイで隠れるので、アップロードしなくても大丈夫です。

アップロード画像は、フロント／バックジャケット1435×1435px、バックインレイ表／裏1771×1393pxの指定サイズに合わせて、縦横比を保たずに調整されます。 対応形式はPNG / JPGです。ディスクは指定した外径をもとに300 DPIで調整されます。 画像処理はブラウザー内で行われます。

A4・2ページジャケット＋バックインレイは、PDFでも画像（PNG / JPG）でも書き出せます。 4ページ以上のブックレットは、ページ画像とバックインレイを一緒のPDF／画像にするか、別々にするかを選べます。

「プロジェクトを保存」で、元画像、ブックレットページ、作品情報、設定、レイヤーとフォルダー、読み込み済みフォントをJSONファイル1つにまとめます。 次回は「プロジェクトを読み込む」から保存したJSONファイルを読み込むだけで、一括で復元できます。

GitHub / README

GitHubに置いてあるテンプレート（JSON）を読み込んで、そのままプロジェクトとして開きます。 読み込むと現在の作業内容は置き換わります。インターネット接続が必要です。

テンプレートをテスト印刷して切り取る場合は、黒い枠線の内側ではなく、枠線の外側（線の外縁）に沿って切り取ってください。 内側で切ると、線の太さの分だけ小さくなります。

ブックレット作成（2・4・8・12ページ）

各ページの画像を個別に読み込みます。 ページ数は2・4・8・12ページからボタンで選択できます（用紙レイアウトの書き出しは4ページ以上が対象です）。 2ページの場合は1枚の用紙の表面と裏面としてプレビューし、ページ1はフロントジャケット、ページ2はバックジャケットにも反映されます。 4ページ以上は、表紙を開いて左右ページを見開き表示し、左右ページをクリック／タップするか前後ボタンで読み順にめくれ、最終ページから表紙へ閉じられます。 ドラッグまたは左右回転ボタンで冊子全体を360度回せ、ズームして確認できます。各ページには1から最終ページまでの番号を表示します。 面付けの見開きサイズは24.15 × 12.15 cmです。 A3縦向き両面では、表面にページ4（左）とページ1（右）の見開きを置き、バックインレイ表を下段に配置します。裏面はページ2（左）とページ3（右）、バックインレイ裏を下段に配置します。 8ページでは表面に8｜1の下へ6｜3、裏面に2｜7の下へ4｜5を配置し、12ページでは下段の見開きを追加のA3用紙に配置します。 各ページ画像は120.75 × 121.5 mm、バックインレイは300 DPIの実寸です。

印刷について
家庭用プリンターでは、PCのAdobe Acrobat ReaderでPDFを開き、印刷倍率を「実際のサイズ」または100%にしてください。 スマートフォンでは「ぴたプリ」など実寸印刷に対応したアプリの利用をおすすめします。 印刷業者へ入稿する場合は、各業者のデータ作成ガイドを確認してください。 チラシ・フライヤー印刷、またはそれに近しいものを選択し、用紙サイズを選んで入稿し、書き出したPDFの用紙サイズもご確認ください。 プリンター、アプリ、PDF閲覧ソフト、業者の設定や仕様によって実寸印刷ができない場合があり、その印刷結果についてアプリの提供者は責任を負いません。 ブラウザでPDFや画像を開いて印刷すると、印刷可能領域に合わせる拡大が入って実寸より大きく印刷されることがあります。 その場合は「書き出し」で形式に「印刷」を選び、このアプリから直接印刷してください（用紙サイズぴったりの設定で印刷できます）。 それでも大きい／小さい場合は、印刷の「サイズ補正（mm）」で調整できます。ブラウザ印刷では0.5mmほど大きく出るため、サイズ補正は -0.5 を推奨します（初期値も -0.5 にしてあります）。

書き出し

PDFと同じ配置のまま、画像（PNG / JPG）でも書き出せます。対象は「A4・2ページジャケット＋バックインレイ」「ブックレット」「A3両面・ページ＋バックインレイ」「A4・ページ別」「A4・バックインレイ」です。各ページをA4／A3／見開きサイズの実寸・300 DPI相当で描くので、ぴたプリなど実寸印刷アプリでは「画像」を選んでください。複数ページになる場合はZIPにまとめて保存します。形式で「印刷」を選ぶと、用紙サイズぴったりの設定でこのアプリから直接ブラウザ印刷もできます。PDFや画像ファイルをブラウザで開いて印刷すると拡大されて実寸より大きくなることがあるため、ブラウザで印刷する場合はこちらがおすすめです。印刷結果が大きい／小さい場合は「サイズ補正（mm）」で調整できます。ブラウザ印刷では0.5mmほど大きくなるため、まずは -0.5 がおすすめです（初期値も -0.5 にしてあります）。 選択肢を変えるか「プレビュー」ボタンを押すと、書き出しレイアウトをポップアップで確認できます（A3以外のレイアウトもすべてプレビューできます）。
