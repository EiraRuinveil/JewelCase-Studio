# JewelCase Studio

CDジュエルケース用アートワークを読み込み、ケースをプレビューし、印刷用データを作成するHTML単体のアプリです。画面右上で日本語と英語を切り替えられます。

## 起動方法

[https://eiraruinveil.github.io/JewelCase-Studio/](https://eiraruinveil.github.io/JewelCase-Studio/)
を開いてください。PDF保存にはjsPDFをCDNから読み込むため、PDF出力時はインターネット接続が必要です。画像処理はブラウザー内で行われます。

## テンプレート

それぞれの部位に名前をつけたテンプレート、2ページジャケット・バックインレイ表裏と、ページ番号付きのテンプレート、8ページブックレット・バックインレイ表裏があります
テスト印刷などにお使いください

下記のファイルをダウンロードし、プロジェクトを読み込むボタンを押してお使いください。
サイト内の「テンプレート読み込み」ボタンからも、GitHub上のテンプレートを直接読み込めます（インターネット接続が必要です。読み込むと現在の作業内容は置き換わります）。

テンプレートをテスト印刷して切り取る場合は、黒い枠線の内側ではなく、枠線の外側（線の外縁）に沿って切り取ってください。内側で切ると、線の太さの分だけ小さくなります。

## ジャケットとディスク

| 部位 | 画像サイズ | 対応形式 |
|---|---:|---|
| フロント／バック ジャケット | 1435 × 1435 px | PNG / JPG |
| バックインレイ表／裏 | 1771 × 1393 px | PNG / JPG |
| ディスク | 指定した外径をもとに300 DPIで調整 | PNG / JPG |

アップロード画像は指定サイズに合わせて縦横比を保たずに調整されます。バックインレイ裏はディスクトレイが透明ではない場合、バックインレイ裏の部分はディスクトレイで隠れるのでアップロードしなくても大丈夫です。

## 操作

- アーティスト名、アルバムタイトル、カタログ番号を入力できます。アーティスト名とタイトルはハイフンでつないで背表紙に表示します。
- 背表紙のタイトルとカタログ番号は、それぞれ位置、文字サイズ、色、フォントを調整できます。フォントファイルも読み込めます。「フォントを探す（簡易フォントブラウザ）」では、名前検索とプレビューでフォントを探して、背表紙や文字レイヤーに設定できます。Google Fonts（要インターネット接続）と端末のフォントが対象です。
- 左右の背表紙文字は−90度／＋90度に回転し、Y位置を反転して配置します。
- 3Dプレビューはドラッグで回転できます。PCではShift＋ドラッグまたは位置スライダー、タッチ端末ではタッチ操作で移動します。ケースの開閉、ディスクの着脱、60〜180%のズームも操作できます。ブックレットは左綴じで、開閉・回転しながら面付けページをめくって確認できます。
- ブックレットは2・4・8・12ページをボタンで選択できます。表紙を開いて左右ページを見開き表示し、左右ページをクリック／タップするか前後ボタンで読み順にめくれ、最終ページから表紙へ閉じられます。ドラッグまたは左右回転ボタンで冊子全体を360度回し、ズームして確認できます。各ページに1から最終ページまでの番号を表示します。2ページの場合は、ページ1がフロントジャケット、ページ2がバックジャケットにも反映されます（ジャケット側にアップロードした場合も、2ページのブックレット側に反映されます）。2ページのプレビューは、1枚の用紙の表面（ページ1）と裏面（ページ2）を1枚ずつ表示し、ボタンやクリックで裏返せます。
- プレビュー右側の「レイヤーでデザイン」から画像レイヤーと文字レイヤーを追加できます。各レイヤーはフロントジャケット、バックジャケット、バックインレイ表／裏、ディスクのいずれかに割り当てられます。
- レイヤーごとに表示切替、重なり順、フォルダー分け、不透明度、ブレンドモード、指定色への変更を設定できます。色変更では画像の透明部分を保持します。レイヤー設定と一覧は個別に折りたためます。
- 文字レイヤーは文字列、文字サイズ、文字色、フォントを個別に設定できます。標準フォントのほか、フォントファイル（TTF / OTF / WOFF / WOFF2）を読み込めます。
- 選択したレイヤーは「移動・変形モード」でプレビュー上をドラッグして移動できます。移動・変形モードはデフォルトでオフで、レイヤーを追加・選択しても自動ではオンになりません。必要なときだけボタンでオンにしてください。拡大縮小スライダーはレイヤー全体に適用されます。ダークモードは画面右下のボタンで切り替えられ、設定はブラウザーに保存されます。
- フロントジャケットとバックジャケットは2ページジャケット専用です。A4で2ページジャケットとバックインレイを印刷する場合に使用します。

## PDF出力

- **A4・2ページジャケット＋バックインレイPDF**：1ページ目にフロントジャケットとバックインレイ表、2ページ目にフロントジャケットとバックインレイ裏を配置され出力します。
- **ブックレットPDF**：4・8・12ページの画像を小冊子の順番に面付けし、24.15 × 12.15 cmの見開きPDFにします。
- **A3・ページ＋バックインレイPDF**：A3縦向きの両面PDFです。4ページの場合、表面にページ4（左）とページ1（右）、バックインレイ表を下段に配置します。裏面はページ2（左）とページ3（右）、バックインレイ裏を下段に配置します。各4ページ分の見開きをA3用紙の上から下へ追加します。8ページでは表面に8｜1の下へ6｜3、裏面に2｜7の下へ4｜5を配置します。12ページでは下段の見開きを追加のA3用紙に配置します。各ページ画像は120.75 × 121.5 mm、バックインレイは300 DPIの実寸です。
- **A4横・ブックレット両面PDF**と**A4・バックインレイPDF**：ブックレットページとバックインレイを別ファイルで出力します。A4横向きのブックレットPDFは4ページごとに区切り、各グループの表面に最後と最初のページ、裏面に中央の2ページを見開きで配置します。見開き全体（241.5 × 121.5 mm）はA4横向き用紙の中央に実寸配置し、バックインレイは各面を別ページに実寸配置します。
- **ディスク120×120mm PDF**：120 × 120 mmのページにディスクを中央配置します。

A3/A4のブックレット用PDFでは、ブックレット画像とバックインレイを一緒にするか、別々にするかを選べます。各画像のプレビューで右クリックして「名前を付けて画像を保存」を選ぶと、個別保存もできます。

## 画像出力

「書き出し」で形式に「画像」を選ぶと、PDFと同じ配置のまま、PNG / JPGでも書き出せます。画像形式（PNG / JPG）はダイアログで選択できます。PNGには300 DPI情報を付けます。各ページは用紙サイズの実寸・300 DPI相当で描きます。複数ページになる場合はZIPにまとめて保存します。

- **A4・2ページジャケット＋バックインレイ画像**：PDF版と同じく、1ページ目にフロントジャケットとバックインレイ表、2ページ目にバックジャケットとバックインレイ裏を配置した画像2点をZIPで出力します。
- **ブックレット画像**：ブックレットPDFと同じ見開き順（24.15 × 12.15 cm）で、見開きごとに画像を出力します。
- **A3両面・ページ＋バックインレイ画像**：A3 PDFと同じ面付けで、A3縦向き・面ごとに画像を出力します。
- **A4・ページ別画像**：A4横向き・用紙（面）ごとに画像を出力します。
- **A4・バックインレイ画像**：バックインレイの各面をA4縦向きに実寸配置した画像を出力します。表だけの場合は1ファイル、表裏の場合はZIPになります。

## 書き出しレイアウトのプレビュー

「書き出し」ダイアログで「用紙サイズ・出力内容」の選択肢を変えると、そのレイアウトのプレビューがポップアップで表示されます（「プレビュー」ボタンからも開けます）。対象はA4・2ページジャケット＋バックインレイ、ブックレット、A3両面、A4・ページ別、A4・バックインレイ、ディスクのすべてで、形式（PDF／画像／印刷）によらず、書き出しと同じレイアウトが表示されます。実寸（mm）とページ数も表示され、複数ページの場合は番号付きで全ページが並びます。画像が不足している場合は、ポップアップ内に案内が表示されます。

## プロジェクトの保存

「プロジェクトを保存」で、元画像、ブックレットページ、作品情報、設定、レイヤーとフォルダー、読み込み済みフォントをJSONファイル1つにまとめます。次回は「プロジェクトを読み込む」から一括で復元できます。

各部位（フロントジャケット、バックジャケット、バックインレイ表／裏、ディスク）は、アップロード欄の「この部位をリセット」でその部位だけを消せます。ブックレットの各ページにもリセットボタンがあり、2ページの場合はジャケット側も連動して消えます。

バックインレイの横幅調整（両端6mm対策）: 元画像の文字やデザインが左右端の6mm（背表紙部分）まである場合、「バックインレイの横幅を内側に調整する」にチェックを入れると、バックインレイ表／裏のプレビュー両端に丸いハンドルが出ます。片方を内側へドラッグすると、もう片方も同じ量だけ動き、画像全体が左右対称に縮んで内側に収まります（スライダーでも調整でき、設定はプロジェクトに保存されます）。

Windowsの標準フォントは C:\Windows\Fonts にあります。ブラウザの仕様上、ファイル選択ダイアログの最初のフォルダーはサイト側から指定できないため、フォント設定欄にパス表示とコピーボタンを用意しています（ダイアログのアドレス欄に貼るとそのフォルダーを開けます）。

## 印刷について

家庭用プリンターでは、PCのAdobe Acrobat ReaderでPDFを開き、印刷倍率を「実際のサイズ」または100%にしてください。スマートフォンでは「ぴたプリ」など実寸印刷に対応したアプリの利用をおすすめします。
A3・A4での画像書き出しに対応しました（上記「画像出力」を参照）。ブラウザでPDFや画像を開いて印刷すると拡大されて実寸より大きくなる（0.5mm程度）場合は、「書き出し」で形式に「印刷」を選び、アプリから直接印刷してください。用紙サイズぴったりの設定で印刷でき、それでも大小する場合は印刷の「サイズ補正（mm）」で調整できます。ブラウザ印刷では0.5mmほど大きく出るため、サイズ補正は -0.5 を推奨します（初期値も -0.5 にしてあります）。

印刷業者へ入稿する場合は、各業者のデータ作成ガイドを確認してください。
チラシ・フライヤー印刷、またはそれに近しい物を選択し、用紙サイズを選び入稿してください。書き出したPDFの用紙サイズもご確認を。
プリンター、アプリ、PDF閲覧ソフト、業者の設定や仕様によって実寸印刷ができない場合があります。印刷結果について、アプリの提供者は責任を負いません。
