# CD Artwork Maker

CDジュエルケース用の画像をブラウザ内で調整し、PNGのZIP出力とA4・2ページPDF出力ができる静的Webアプリです。



## 仕様

- フロントジャケット: 1435 × 1435 px
- バックジャケット: 1435 × 1435 px
- バックインレイ表・裏: 1771 × 1393 px
- ディスク: 1394 × 1394 px、外径約118 mm、中央穴23 mm
- 背表紙表記: `アーティスト名 - アルバムタイトル   カタログ番号`
- 左側背表紙は下から上、右側背表紙は上から下の向き
- 入力画像は指定寸法に合わせて縦横比を維持せずにリサイズします。
- PNG形式でZIP出力します。300 DPI相当の解像度情報を付加します。
- PDF出力はA4縦・2ページ構成です。1ページ目はフロントジャケット＋バックインレイ表、2ページ目はバックジャケット＋バックインレイ裏を配置します。上下余白は各15 mm、配置寸法は300 DPI基準の実寸です。
- PDF出力にはjsPDFをCDNから読み込みます。PDF出力時はインターネット接続が必要です。
- 画像処理は利用者のブラウザ内で行われ、画像ファイルをサーバーへアップロードしません。

## 注意

画面のジュエルケース画像は完成イメージ確認用の簡易モックアップです。ケースの実寸・反射・印刷物の物理的な重なりを厳密に再現する製版図ではありません。印刷所・プレス業者の入稿仕様がある場合は、そちらを優先してください。
