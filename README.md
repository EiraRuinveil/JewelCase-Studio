# JewelCase Studio

CDジュエルケース用アートワークを読み込み、ケースをプレビューし、印刷用データを作成するHTML単体のアプリです。画面右上で日本語と英語を切り替えられます。

## 起動方法

[https://eiraruinveil.github.io/JewelCase-Studio/](https://eiraruinveil.github.io/JewelCase-Studio/)
を開いてください。PDF保存にはjsPDFをCDNから読み込むため、PDF出力時はインターネット接続が必要です。画像処理はブラウザー内で行われます。

## テンプレート

それぞれの部位に名前をつけたテンプレート、2ページジャケット・バックインレイ表裏と、ページ番号付きのテンプレート、8ページブックレット・バックインレイ表裏があります
テスト印刷などにお使いください
2ページジャケットでバックインレイ表裏あります

下記のファイルをダウンロードし、プロジェクトを読み込むボタンを押してお使いください。

## CD cover とディスク

| 部位 | 画像サイズ | 対応形式 |
|---|---:|---|
| フロント／バック CD cover | 1435 × 1435 px | PNG / JPG |
| バックインレイ表／裏 | 1771 × 1393 px | PNG / JPG |
| ディスク | 指定した外径をもとに300 DPIで調整 | PNG / JPG |

アップロード画像は指定サイズに合わせて縦横比を保たずに調整されます。ケースのトレイが透明でない場合、バックインレイ裏の画像データは不要です。

## 操作


- アーティスト名、アルバムタイトル、カタログ番号を入力できます。アーティスト名とタイトルはハイフンでつないで背表紙に表示します。
- 背表紙のタイトルとカタログ番号は、それぞれ位置、文字サイズ、色、フォントを調整できます。フォントファイルも読み込めます。
- 左右の背表紙文字は−90度／＋90度に回転し、Y位置を反転して配置します。
- 3Dプレビューはドラッグで回転できます。PCではShift＋ドラッグまたは位置スライダー、タッチ端末ではタッチ操作で移動します。ケースの開閉、ディスクの着脱、60〜180%のズームも操作できます。ブックレットは左綴じで、開閉・回転しながら面付けページをめくって確認できます。
- ブックレットは2・4・8・12ページをボタンで選択できます。表紙を開いて左右ページを見開き表示し、左右ページをクリック／タップするか前後ボタンで読み順にめくれ、最終ページから表紙へ閉じられます。ドラッグまたは左右回転ボタンで冊子全体を360度回し、ズームして確認できます。各ページに1から最終ページまでの番号を表示します。

## PDF出力

- **A4・2ページPDF**：CD cover用の2ページ出力です。各ページに対応するジャケットとインレイ表裏を配置します。バックインレイ裏はディスクトレイが透明ではない場合、バックインレイ裏の部分はディスクトレイで隠れるのでアップロードしなくても大丈夫です。
- **ブックレットPDF**：2・4・8・12ページの画像を小冊子の順番に面付けし、24.15 × 12.15 cmの見開きPDFにします。4の倍数でないページ数では白紙ページを追加します。
- **A3・ページ＋バックインレイPDF**：A3縦向きの両面PDFです。4ページの場合、表面にページ4（左）とページ1（右）、バックインレイ表を下段に配置します。裏面はページ2（左）とページ3（右）、バックインレイ裏を下段に配置します。各4ページ分の見開きをA3用紙の上から下へ追加します。8ページでは表面に8｜1の下へ6｜3、裏面に2｜7の下へ4｜5を配置します。12ページでは下段の見開きを追加のA3用紙に配置します。各ページ画像は120.75 × 121.5 mm、バックインレイは300 DPIの実寸です。
- **A4横・ブックレット両面PDF**と**A4・バックインレイPDF**：ブックレットページとバックインレイを別ファイルで出力します。A4横向きのブックレットPDFは4ページごとに区切り、各グループの表面に最後と最初のページ、裏面に中央の2ページを見開きで配置します。見開き全体（241.5 × 121.5 mm）はA4横向き用紙の中央に実寸配置し、バックインレイは各面を別ページに実寸配置します。
- **ディスク120×120mm PDF**：120 × 120 mmのページにディスクを中央配置します。

A3/A4のブックレット用PDFでは、ブックレット画像とバックインレイを一緒にするか、別々にするかを選べます。各画像のプレビューで右クリックして「名前を付けて画像を保存」を選ぶと、個別保存もできます。

## プロジェクトの保存

「プロジェクトを保存」で、元画像、ブックレットページ、作品情報、設定、読み込み済みフォントをJSONファイル1つにまとめます。次回は「プロジェクトを読み込む」から一括で復元できます。

## 印刷について

家庭用プリンターでは、PCのAdobe Acrobat ReaderでPDFを開き、印刷倍率を「実際のサイズ」または100%にしてください。スマートフォンでは「ぴたプリ」など実寸印刷に対応したアプリの利用をおすすめします。

印刷業者へ入稿する場合は、各業者のデータ作成ガイドを確認してください。プリンター、アプリ、PDF閲覧ソフト、業者の設定や仕様によって実寸印刷ができない場合があります。印刷結果について、アプリの提供者は責任を負いません。
